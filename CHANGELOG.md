# Changelog

## 0.2.0 - 2026-11-25

### Added

- The Overview top-artist chart, Artist directory, and artist profiles show Spotify follow status below each artist name. A pink checkmark marks **Following**. A muted dot marks **Not following**. Unknown status stays hidden.
- Existing Spotify connections must reconnect in Settings to approve read access to artist follows. A library sync is not necessary.

## 0.1.0

- Initial local dashboard for Spotify saved tracks, with library sync, artist profiles, filters, charts, exports, and demo mode.
